# Changelog

Notable changes to `svelte-topbar` are documented here. Versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-11-10

### Changed

- Publish GitHub releases to npm using Trusted Publishing (OIDC).
- Include this changelog in the published package.

## [1.0.0] - 2026-11-10

### Added

- Svelte 5 top loading bar powered by NProgress.
- Automatic tracking for eligible same-origin links, with configurable props.
- Imperative controls through `createTopLoader()`.
- Optional SvelteKit navigation adapter.
